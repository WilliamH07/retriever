# Bill of materials

The costed BOM lives in the architecture dossier, section S of
[`docs/architecture/06-bom-fmea-schema-plan.md`](../../docs/architecture/06-bom-fmea-schema-plan.md).

It is split into what is already owned, what must be bought for the robot to be
built safely, what is recommended, and what is optional.

One rule runs through it: where a part could not be verified, the minimum
specification to respect is given instead of a product reference. A
specification stays valid for years; a part number is obsolete in months.
